2. Calculation and interface checks

  • Finite, nonnegative edge weights and the documented cost formula.
  • Reverse multi-source category costs match forward Dijkstra spot checks.
  • Client-displayed route weights sum to the same cached block score.
  • Category selection, empty selections, ranking filters, route highlighting, category changes and CSV download tested in Chrome.
  • City boundary and one-kilometer routing/destination buffer are explicit.

These checks establish implementation consistency. They do not certify real-world sidewalk access or safety.

3. Time-only versus friction-weighted recommendations

On the same supported graph and eligible housing-block set, essential-service ranking correlation is 0.994. 19 of the top 20 blocks overlap. Distance is therefore a major driver under this bounded penalty model.

Prioritizing canopy, traffic or heat with 60/20/20 factor weights retained the same top-20 set in this test. This is a robustness observation, not proof that the model reflects people's preferences.
